# projects/

Compiled wiki layer for actively built things — products, campaigns, initiatives. One subfolder per project. Suggested canonical pages inside each project folder:

```text
projects/<project>/
  README.md      # folder index
  context.md     # durable background and positioning
  status.md      # current state, blockers, next actions
  research/      # market/user/research synthesis
  ops/           # runbooks, infrastructure, recurring ops
```

Not every project needs all of these — create only what's useful. Patch these canonical pages in place rather than creating a new dated note that duplicates them.

See [../schema.md](../schema.md) for note types and frontmatter.
