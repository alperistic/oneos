# inbox/

Temporary landing zone for untriaged captures — quick notes, imports, anything not yet filed. Nothing here should sit for long. Process it into `sources/` (if it's raw evidence) or into the right project/decision/ops note (if it's distilled knowledge), then remove it from here or mark it processed.

See [../schema.md](../schema.md) and [../RESOLVER.md](../RESOLVER.md) for where things belong once triaged.
