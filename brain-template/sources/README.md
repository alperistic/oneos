# sources/

Raw or near-raw evidence: original documents, copied source text, transcripts, imported files, source summaries. Preserve source meaning — do not silently rewrite a source as if it were compiled knowledge. If a source is superseded or wrong, mark it, don't delete it.

Suggested subfolders: `sources/research/`, `sources/projects/`, `sources/meetings/`.

See [../schema.md](../schema.md) for the full layer model.
